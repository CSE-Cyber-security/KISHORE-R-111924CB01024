# Week 2 - Factorial Program

## Problem Statement
Write a Python program to find the factorial of a given number.

## Program
The program takes an integer as input and calculates its factorial using a `for` loop.

## Example

### Input
Enter a number: 5

### Output
Factorial of 5 = 120
