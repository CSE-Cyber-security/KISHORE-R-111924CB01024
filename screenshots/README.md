# Screenshots

The specification requests screenshots for:
1. Add asset
2. Display assets
3. Search asset
4. Update asset
5. Delete asset
6. Security summary
7. Input validation

Run the application and capture these seven states for submission. The
filenames should be:

- `01-add-asset.png`
- `02-display-assets.png`
- `03-search-asset.png`
- `04-update-asset.png`
- `05-delete-asset.png`
- `06-security-summary.png`
- `07-input-validation.png`
