# Password Strength Checker

A simple Python command-line project that checks password strength.

## Requirements
- Python 3.8 or later
- No external packages required

## Run
Open a terminal in this folder and run:

```bash
python password_strength_checker.py
```

On Windows, you can also use:

```bash
py password_strength_checker.py
```

The program checks password length, uppercase and lowercase letters,
numbers, special characters, common passwords, repeated characters,
and predictable sequences.

The password is entered using a hidden prompt and is evaluated locally.
This is an educational checker, not a guarantee that a password is secure.
